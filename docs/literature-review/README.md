# Literature Review

This directory contains the literature review for the research project.

## Purpose

To identify, analyze, and compare existing academic research related to payment authentication security.

## Research Areas

1. Authentication mechanisms in online payment systems.
2. Multi-factor authentication (MFA).
3. One-Time Password (OTP) security.
4. Man-in-the-Middle (MITM) attacks.
5. Phishing and social engineering attacks.
6. SIM swapping and SMS-based authentication vulnerabilities.
7. Authentication protocols and standards.
8. Emerging authentication technologies.
