# Research Diagrams

This directory contains visual representations supporting the research.

## Diagramming Tools

- Mermaid: Text-based diagrams maintained in Git.
- draw.io: Visual diagrams exported as SVG or PNG.

## Planned Diagrams

1. Payment authentication system architecture.
2. Authentication sequence diagram.
3. Threat model and attack flow.
4. Security control workflow.
5. Proposed authentication framework.

## File Organization

- `.mmd` — Mermaid diagram source files.
- `.drawio` — Editable draw.io diagrams.
- `.svg` — Vector diagram exports.
- `.png` — Raster diagram exports.

All diagrams should include descriptive titles and be referenced in the relevant research documentation.
